# 初始化规则 🧰

`init` 子命令用于将 Nacos 导出的目录或 zip 转换为可维护的模板：按路径规则替换为占位符、按需应用正则替换，并汇总示例变量（支持掩码）。

**规则文件结构（YAML）**
```yaml
version: 1
mask_keywords: [PASS, PASSWORD, SECRET, TOKEN, AK, SK, KEY]
matchers:
  - when:
      ext: yaml            # yaml|json|properties
      path_glob: "**/*.yml"  # 可选，命中才生效
    replace:               # 键路径 -> 占位符
      db.user: "${DB_USER}"
      db.pass: "${DB_PASS}"
  - when:
      ext: properties
    replace:
      kafka.bootstrap.servers: "${KAFKA_BOOTSTRAP}"
    regex_replace:
      - pattern: "(?i)password=([^;&\n]+)"
        to: "password=${DB_PASS}"
  - when:
      ext: json
    regex_replace:
      - pattern: "(?i)\"password\"\s*:\s*\"[^\"]+\""
        to: "\"password\": \"${DB_PASS}\""
```

**工作方式**
- replace：按“点路径”精确替换（YAML/JSON/Properties）。
- regex_replace：按正则进行文本级替换（Properties/JSON 支持）。
- 示例变量：当替换目标包含 `${VAR}`，会记录原值到 `variables.example.yaml`；若变量名含敏感关键词（命中 `mask_keywords`），则写为 `******`。🔒

**输出结果**
- 保留原目录层级，文件内容替换为占位符后的模板。
- 在输出根目录生成 `variables.example.yaml`（可通过配置/环境变量改名）。

**常见示例**
```yaml
# 将 spring 配置中的连接地址替换为占位符
matchers:
  - when: { ext: yaml, path_glob: "**/application*.yml" }
    replace:
      spring.datasource.url: "${DB_URL}"
      spring.datasource.username: "${DB_USER}"
      spring.datasource.password: "${DB_PASS}"
```

**提示**
- path_glob 使用路径相对于输入根目录的 Unix 风格（`/` 分隔）。
- 属性文件解析较朴素，复杂转义/多行可通过 regex_replace 补齐。🧵
