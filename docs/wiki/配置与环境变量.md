# 配置与环境变量 🔧

**配置发现顺序（低 → 高优先级）**
- 用户目录：`~/.nacos-tpl/config.yaml`（或 `XDG_CONFIG_HOME/nacos-tpl/config.yaml`）
- 项目目录：`.nacos-tpl/config.yaml` 或 `nacos-tpl.yaml`
- 显式路径：`--config <path>`
- 环境变量：覆盖配置中的同名项
- 命令行参数：最高优先级

**Profile 选择**
- 顺序：`--profile` > `NACOS_TPL_PROFILE` > `active_profile`
- 命中后会将该 profile 的内容覆盖到生效配置。🎯

**配置项一览（片段）**
```yaml
version: 1
server: http://127.0.0.1:8848 # 或 servers: [http://a, http://b]
namespace: public
username: nacos
password: nacos
token: null
timeout_ms: 10000
tls:
  enabled: true
  insecure: false
  ca_cert: /path/to/ca.pem

render:
  defaults:
    variables_file: examples/vars.yaml
    stdout: false

init:
  defaults:
    example_file: variables.example.yaml
    mask_keywords: [PASS, PASSWORD, SECRET, TOKEN, AK, SK, KEY]
```

**环境变量覆盖（常用）**
- `NACOS_TPL_SERVER` / `NACOS_TPL_SERVERS`
- `NACOS_TPL_NAMESPACE`
- `NACOS_TPL_USERNAME` / `NACOS_TPL_PASSWORD`
- `NACOS_TPL_TOKEN`
- `NACOS_TPL_TIMEOUT_MS`
- `NACOS_TPL_TLS_INSECURE` / `NACOS_TPL_TLS_CA_CERT`
- `NACOS_TPL_RENDER_VARIABLES_FILE` / `NACOS_TPL_RENDER_STDOUT`
- `NACOS_TPL_INIT_EXAMPLE_FILE`

**合并与覆盖规则**
- 基础字段：后者覆盖前者（Option 语义）。
- `servers`：整列表覆盖，不做去重合并（命令行内部会做去重）。
- `render.defaults` / `init.defaults`：按字段覆盖。🧱

**TLS 与证书**
- `tls.insecure=true` 将忽略证书校验（仅用于测试环境）。⚠️
- `tls.ca_cert` 可指定自定义 CA 文件。🪪
