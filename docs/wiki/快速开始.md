# 快速开始 🚀

**准备环境**
- 本地 Nacos（可选）：`docker compose -f scripts/compose/local.yaml up -d` 🐳
- 准备模板与变量：使用仓库内 `examples/` 练手或自建。📂

**典型目录结构**
```text
template/
  DEFAULT_GROUP/
    app.yaml
    log.properties
  PRO_GROUP/
    other.yaml
vars/
  dev.yaml
```

**渲染到目录并写 manifest**
```bash
nacos-tpl render -t examples/template -v examples/vars.yaml -o build/dev --write-manifest
```

**单文件渲染到标准输出**
```bash
nacos-tpl render -t examples/template -v examples/vars.yaml \
  --print DEFAULT_GROUP/app.yaml --stdout
```

**严格校验（残留占位符即失败）**
```bash
nacos-tpl validate -t examples/template -v examples/vars.yaml --strict
```

**远端对比**
```bash
nacos-tpl diff-remote -s http://127.0.0.1:8848 -n public \
  -d build/dev --show-changed --context 5
```

**发布（谨慎操作生产）**
```bash
nacos-tpl apply -s http://127.0.0.1:8848 -n public -d build/dev \
  --skip-unchanged --retries 3 --concurrency 5 --timeout-ms 10000 \
  --normalize-lf --max-bytes 1048576 \
  --json --report dist/apply-report.json
```

**小贴士**
- `--server` 支持逗号分隔多个地址，自动轮询降级。🧩
- 变量文件可为单文件或目录，目录内按文件名顺序合并。📚
- 环境变量（大写）会覆盖同名键，例如 `DB_HOST`。🔧
