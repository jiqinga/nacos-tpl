# 命令详解 📖

本页列出各子命令的用途、主要参数与示例。所有错误提示均为中文并带 emoji，便于定位问题。🧭

**总览**
- `render`：渲染模板到目录或标准输出。
- `init`：从目录/zip 初始化模板并提取示例变量。
- `validate`：校验变量与模板，支持严格模式与规则文件。
- `diff-remote`：对比本地渲染结果与远端 Nacos。
- `apply`：通过 OpenAPI 发布本地配置到 Nacos。
- `package`：将渲染结果打包为 zip。

---

**render**（渲染模板）
- 关键参数：
  - `-t, --template <dir|zip>`：模板目录或 zip。
  - `-v, --vars <file|dir>`：变量文件或目录（目录按文件名排序合并）。
  - `-o, --output <dir>`：渲染到目录。
  - `--print <relpath>`：选择单个文件（相对模板目录）。
  - `--print-id <dataId>` + `--group <group>`：按 dataId/group 选择（需要 manifest 或 front‑matter）。
  - `--stdout`：配合 `--print` 将单文件输出到标准输出。
  - `--allow-missing`：允许缺失变量（保留占位符）。
  - `--include/--exclude <glob,glob>`：子集渲染。
  - `--write-manifest`：目录渲染后写出 `manifest.yaml`。
- 示例：
```bash
nacos-tpl render -t template -v vars.yaml -o build/dev --write-manifest
nacos-tpl render -t template -v vars -o build/dev --include "**/*.yml,**/*.properties"
nacos-tpl render -t template -v vars.yaml --print DEFAULT_GROUP/app.yaml --stdout
nacos-tpl render -t template -v vars.yaml --print-id app.yaml --group DEFAULT_GROUP --stdout
```

---

**init**（初始化模板）
- 关键参数：
  - `-i, --input <dir|zip>`：原始导出目录或 zip 包。
  - `-o, --output <dir>`：输出模板目录。
  - `-r, --rules <file>`：规则文件（YAML），用于路径替换、正则替换与示例变量抽取/掩码。
- 说明：
  - 会生成 `variables.example.yaml`（文件名可由配置/环境变量覆盖）。
  - 支持 `mask_keywords`（如 PASSWORD/TOKEN 等），命中将写入 `******`。🔒
- 示例：
```bash
nacos-tpl init -i export_dir -o template -r mapping.rules.yaml
nacos-tpl init -i export.zip -o template -r mapping.rules.yaml
```

---

**validate**（校验模板与变量）
- 关键参数：
  - `-t, --template <dir>`、`-v, --vars <file|dir>`。
  - `-r, --rules <file>`：必填变量列表（YAML）
  - `--strict`：渲染后不允许残留任何 `${...}` 占位符。
  - `--json` / `--report <path>`：JSON 输出与写文件。
- 示例：
```bash
nacos-tpl validate -t template -v vars/dev.yaml --strict -r rules.yaml --json --report build/validate.json
```
- JSON 结构（示例）：
```json
{
  "ok": false,
  "missing": ["缺失变量:DB_HOST 于 DEFAULT_GROUP/app.yaml", "占位符:${REDIS_URL}"]
}
```

**diff-remote**（本地对比远端）
- 关键参数：
  - `-s, --server <url[,url]>`：单个/多个服务器，缺协议将自动补全为 `http://`。
  - `-n, --namespace <tenant>`：命名空间；为空时可从 `.metadata.yml` 推断。
  - `-d, --dir <path>`：本地目录（通常是 render 输出）。
  - `--include/--exclude <glob,glob>`：过滤参与比对的文件。
  - `--only-changed` / `--only-added`：只打印变更或新增。
  - `--show-changed` / `--no-show-changed`：是否展示差异。
  - `--diff-style <unified|side-by-side>` 与 `--context <n>`：差异风格与上下文行数。
  - `--json` / `--report <path>`：JSON 输出与写文件。
- 示例：
```bash
nacos-tpl diff-remote -s 127.0.0.1:8848 -n public -d build/dev --only-changed --diff-style side-by-side
```
- JSON 结构（示例）：
```json
{
  "same": 10,
  "changed": 2,
  "added": 1,
  "errors": 0,
  "items": [
    {"dataId":"app.yaml","group":"DEFAULT_GROUP","status":"changed"},
    {"dataId":"kafka.properties","group":"DEFAULT_GROUP","status":"same"}
  ],
  "groups": [
    {"group":"DEFAULT_GROUP","same":9,"changed":2,"added":1}
  ],
  "groups_detail": [
    {"group":"DEFAULT_GROUP","changed":["app.yaml"],"added":["redis.yml"]}
  ]
}
```

**apply**（发布配置）
- 关键参数：
  - `-s, --server <url[,url]>`、`-n, --namespace <tenant>`、`-d, --dir <rendered>`。
  - `-u, --username` / `-p, --password`：登录获取 token（也可用配置 `token`）。
  - `--skip-unchanged`：与远端一致则跳过。
  - `--concurrency <N>`：并发发布线程数（默认 5）。
  - `--retries <N>` / `--timeout-ms <ms>`：重试次数与请求超时。
  - `--dry-run`：空跑，仅计算变化。
  - `--max-bytes <N>`：单项内容大小上限（字节）。
  - `--normalize-lf`：统一换行符为 LF 再发布。
  - `--include-md5`：在报告中包含本地 MD5 与字节大小。
  - `--overwrite`：允许覆盖远端已存在的配置（默认不覆盖）。
  - `--create-namespace`：命名空间不存在时自动创建（禁止 public）。
  - `--json` / `--report <path>` / `--report-mode <overwrite|append|timestamp>` / `--fail-on-error`。
- 示例：
```bash
nacos-tpl apply -s http://127.0.0.1:8848 -n public -d build/dev \
  --skip-unchanged --retries 3 --concurrency 5 --timeout-ms 10000 \
  --normalize-lf --max-bytes 1048576 \
  --json --report dist/apply-report.json --report-mode overwrite --fail-on-error
```
- JSON 结构（示例）：
```json
{
  "updated": 3,
  "skipped": 5,
  "failed": 1,
  "items": [
    {"dataId":"app.yaml","group":"DEFAULT_GROUP","status":"updated","sizeBytes":1234},
    {"dataId":"redis.yml","group":"DEFAULT_GROUP","status":"failed","reason":"权限不足"}
  ],
  "groups": [
    {"group":"DEFAULT_GROUP","updated":3,"skipped":5,"failed":1}
  ]
}
```

---

**package**（打包导入）
- 关键参数：`-t, --template`、`-v, --vars`、`-o, --output <zip>`、`--allow-missing`。
- 说明：会将渲染后的文件打包为 zip；为避免控制台提示“未识别条目”，默认不会把 `manifest.yaml` 当作配置项打入 zip。📦
- 示例：
```bash
nacos-tpl package -t template -v vars.yaml -o dist/dev.zip
```
