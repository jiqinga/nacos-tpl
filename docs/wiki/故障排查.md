# 故障排查 🐛🧯

汇总常见问题与定位思路，帮助你快速恢复。日志与错误信息均为中文且配有 emoji，便于识别。

## 网络与认证类 🌐
- 403/未授权：确认 `-u/-p` 是否正确；或在配置中提供 `token`。工具会尝试登录获取 accessToken。
- TLS 校验失败：测试环境可临时设置 `tls.insecure=true` 或传入 `NACOS_TPL_TLS_INSECURE=true`；生产建议配置 `tls.ca_cert`。
- 多节点均失败：检查 `--server` 是否配置了多个节点；网络是否可达；服务端返回码与错误堆栈。

## 命名空间相关 📁
- “命名空间不存在或不可用 🚫”：
  - 确认 `-n` 的 ID 是否正确；public 可留空或显式指定 `public`。
  - 可加 `--create-namespace` 自动创建（禁止 public）。

## 渲染与变量 🧩
- “缺失变量/占位符残留”：
  - 提前使用 `validate --strict` 检查；或渲染时传 `--allow-missing` 观察影响范围。
  - 变量文件可为目录，按文件名排序合并；同名环境变量（大写）会覆盖。
- “模板渲染失败 …”：
  - 多为 Tera 语法或变量名错误；精简模板定位具体文件与位置。

## 对比与发布 🔄
- `diff-remote` 差异过多：
  - 增加 `--include/--exclude` 缩小范围；或使用 `.metadata.yml` 白名单减小集合。
  - 使用 `--diff-style side-by-side`，并放大 `--context` 便于审阅。
- `apply` 发布失败较多：
  - 提高 `--retries` 与 `--timeout-ms`；分批发布或降低 `--concurrency`；先 `--dry-run`。
  - 避免 CRLF 干扰：使用 `--normalize-lf` 统一换行。
  - 禁止无意覆盖：默认不覆盖；如需覆盖请加 `--overwrite`。

## 文件与路径 📂
- “模板路径/输出目录未找到”：确认路径是否存在；zip 输入时确保文件可读；目录写入权限无误。
- 变量 YAML 解析失败：检查缩进、引号、中文符号；如需要，在日志级别上调后重试。

## 退出码参考 🧭
- 1：参数或其他错误
- 2：渲染/校验失败
- 3：IO/解压/解析失败
- 4：网络/认证/远端调用失败

> 若仍无法定位，建议开启更高日志等级（如 `RUST_LOG=nacos_tpl=debug`）并附完整命令与最小复现样例。📄
