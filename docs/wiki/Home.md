# nacos-tpl Wiki 🧭

一个用于 Nacos 配置模板化、校验、对比与发布的命令行工具。坚持 KISS 原则，所有日志、错误与 UI 文案均为中文并配合贴切的 emoji。🎯

**你能用它做什么**
- 渲染模板：Tera + 兼容 `${VAR}` 语法，支持默认值与转义。🧩
- 初始化模板：从目录/zip 导出包生成模板与 `variables.example.yaml`，可配置敏感掩码。🧰
- 对比远端：按 `group/dataId` 文本级对比，支持统一 diff 或左右对比。🔍
- 发布配置：并发推送（线程池）、重试、超时、空跑、大小限制与覆盖策略。🚀
- 打包导入：打成 zip 供 Nacos 控制台导入（自动剔除不必要条目）。📦

**系统要求**
- Linux/macOS/Windows，建议安装最新版 Rust（如从源码构建）。🧪
- 访问 Nacos OpenAPI 的网络权限（用于 diff/apply）。🌐

**退出码约定**
- 1：参数或其他错误 ⚠️
- 2：渲染/校验失败（如缺失变量、占位符残留）🧪
